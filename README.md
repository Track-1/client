## 프로젝트 소개
Track 1은 한 음악 프로듀서의 푸념에서 시작되었습니다.

”앨범을 내야 되는데 수록곡에 피처링 해줄 사람이 없어”

현재 음악 프로듀서들은 보컬을 구하는 데에 대부분 지인을 활용합니다.
하지만 지인 중에 보컬이 없는 경우 사운드클라우드나 인스타그램을 하루 종일 뒤져야 하죠.
Track 1은 이러한 문제를 해결하고자 기획되었습니다.
